## Code introduced

`firmware/include/TelemetryScheduler.h` is a portable C++ scheduler, not a full firmware fork yet. It handles multiple configured targets, sequential polling, timeout, response-tag matching and mobile-app precedence. It does not transmit packets, parse telemetry or publish to the cloud.
